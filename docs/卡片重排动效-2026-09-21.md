# 05 号卡片重排动效

用户从五种预览中选择 05。首轮已安装实现以 460ms 双向重排速览与工作台首页的任务、随笔记和番茄钟卡片，其余模块淡入；玻璃外框随内容展开或收回。以下记录该轮实现与本机更新，后续全页面扩展及安装见文末。

## 实现

- `renderer/window-motion.js` 读取两页可见卡片的实际位置与尺寸，复用目标页真实 DOM；文字保持原字号，用户的组件尺寸、顺序和隐藏设置不变。
- `renderer/window-motion.css` 集中保存时长、曲线和外框裁切参数。没有修改柔焦玻璃配色或透明度。
- 继续使用已修复的窗口交接：源窗口保留，目标窗口先准备静止的动画起始帧；主进程确认绘制后才交接并播放，结束后恢复正常布局。
- 返回速览时使用临时动画画布，结束后将原生窗口恢复到速览高度，并同步玻璃遮罩；渲染层等待对应的视口尺寸到达后解除临时布局。
- `window-handoff.js` 校验几何数据、发送窗口和事务编号。IPC 只传对应卡片的矩形，不传页面内容或图片。过期完成回调不能影响新一次切换。
- 连续切换、Esc、窗口关闭和页面变化均清理动画与占位元素；已交接的窗口不会因取消而恢复旧页面。
- 系统开启“减少动态效果”、进入其他功能页或没有对应卡片时，使用已准备页面的直接交接。

数据存储结构与权限不变。动效不会开启摄像头或麦克风。
