## 需要准确理解的边界

这不是当前开发工作区 npm test 的全量通过声明。现有安装版是 1.4.17，工作区为 1.5.1；部分源码测试要求新版卡片分组、卡片顺序、点击直接进入工作台和悬停任务预览，与这个旧安装版的交互设计不同。针对本次包的测试明确保留旧版顺序与任务列表，并独立验证控件、列表、媒体释放及所有修复，未把新版分组/新入口测试算作通过。若需要完整交付 README 中的新入口设计，需要另做源码版本的完整构建与验收。

真实主进程检查仅隔离了系统副作用：不修改这台 Mac 的开机启动项/全局快捷键、不弹系统授权、不解密真实凭据，并将通知 HTTP 端口移到临时端口。操作系统的真实首次授权、摄像头/麦克风硬件、第三方 API 和 AI 工具真实账号连接未全量实测。

本机验证不能代替朋友的 M3/macOS 实机验收。此包为 ad-hoc 签名，未有 Developer ID 签名或 Apple 公证；签名完整性通过不表示 Gatekeeper 必然放行。安装说明已经明确首次拦截处理方法，不要求关闭系统安全机制。
