# 浮岛 · 四款灵动岛效果参考

参考：[休康《MacBook 改造指南：刘海变身灵动岛》](https://www.douyin.com/video/7491890285136350501)，视频发布于 2025-04-11，时长约 7 分 16 秒。本页按视频画面与字幕记录，不将当年的价格或兼容性描述当作当前结论。

| 视频片段 | 展示的方向 | 本轮浮岛实现 |
| --- | --- | --- |
| 00:30 Alcove | 黑色紧凑岛体、短暂向下展开、双指左右切歌 | 黑色 256px 折叠岛与 56px 高任务预览，展开、停留与收回保持贴顶连续 |
| 02:17 MediaMate | 音量与亮度状态条、多种 HUD 样式 | 授权后由浮岛接管音量、静音和内置屏亮度按键，真实读写、变化监听并在停止操作后收回 |
| 03:49 NotchNook | 音乐、日历、镜子横向分区，文件托盘，实时活动样式 | 1240 × 270 横向首页按 Codex、番茄钟、日历、笔记、时钟和应用组织，镜子按需开启 |
| 05:22 boringNotch | 模块化音乐、周历与文件托盘 | 本机周历、待办数量、AI 任务分组和进入完整工作台的快捷入口 |

静置态由中央 **200px** 刘海安全区和左右各 **28px** 侧翼组成，总宽 **256px**，高度与当前菜单栏一致，下方两角为 **17px**。左侧只显示白色 **13px** Codex 剩余额度数字，不显示进度条；右侧空闲为白色 Codex 图标，运行中为白色连续旋转圆环，等待权限、等待输入、失败或中断为静态白色感叹号。

鼠标悬停 **400ms** 显示 **256 × 56px** 任务预览，移开 **250ms** 收回；预览不抢焦点。点击刘海、回车或空格直接打开完整工作台并获取焦点。工作台左上「← 浮岛」返回 **1240 × 270px** AI 优先横向首页，现有工作区尺寸、数据和存储格式保持不变。动画由渲染层负责，原生窗口不执行系统尺寸动画，并响应减少动态效果设置。

Codex 完成提醒与折叠岛同宽，菜单栏安全区下增加 **28px** 内容；任务名居中，右侧白色 Codex 图标转为中性灰底白勾，再停留 **3 秒** 收回。生命周期 Hook 最多同时追踪 **32** 个任务；长任务不按静默时间或跨天过期，等待用户处理优先于被动录音和番茄钟状态显示。

音量由 macOS 输出设置读取与调整，不采集系统声音。「设置 → 音量与亮度 → 用浮岛显示」开启且用户已授予辅助功能权限时，浮岛接管音量、静音和内置屏亮度媒体键并阻止相同按键触发系统原生提示；尚未授权、权限失效、功能关闭或应用退出时，将按键交还系统处理。系统控制中心或其他软件主动显示的界面不属于按键接管范围。

输出设备切换、Mac 电池供电变化已接入。周历为本机日期导航和浮岛待办，不表示已连接 Apple 日历。视频里的播放控制、文件暂存、隔空投送、自定义 GIF、锁屏及键盘背光等不在当前已实现清单；用户已明确无需 iPhone 同步，本轮也未导入参考产品代码。

## 验证入口

- `npm test`：现有工作台、横向首页、悬停预览、Codex 生命周期、镜子生命周期、系统状态服务、活动优先级及独立 HUD 回归。
- `npm start`：从当前源码运行；打包安装另按项目的明确确认要求执行。
- 界面测试使用隔离配置与模拟系统返回值，不改变实际音量、亮度或用户数据。
