# 浮岛交互与首页改版：需求对齐稿

日期：2026-09-04。用户已确认仅处理 Mac 自身状态，不同步 iPhone。本文件保留本次设计规格与接入差距；实际已实现行为以 README 为准。

## 用户已明确的方向

1. 第一张参考图：采用 MediaMate 的贴顶黑色刘海反馈。用户通过电脑键盘或系统控件调整音量、亮度时，浮岛自动响应、显示图标和真实数值，停止操作后收回；岛内也可以直接拖动调节。
2. 第二张参考图：浮岛默认展开首页改为 NotchNook 的横向布局，保持同类宽高比例、三栏比例、封面与镜子尺寸关系。
3. 产品继续使用「浮岛」名称。音乐仍以网易云为目标，需要区分“打开客户端”和“岛内显示真实播放信息”。

## 参考与尺寸

- 系统反馈参考：`../视频分析/四款灵动岛对比/截图/MM07-03m29s-刘海样式与屏幕分类.jpg`。借鉴的是其中黑色刘海内的反馈方式；设置页面并非首页设计。
- 首页参考：`../视频分析/四款灵动岛对比/截图/NN01-03m57s-音乐日历与镜子入口.jpg`。
- 视频截图有缩放、顶部贴屏及轻微裁切，因此采用比例范围，不把视频像素当成应用逻辑像素。

| 项目 | 设计规格 |
| --- | --- |
| 岛体宽高比 | 约 4.3∶1，可接受参考测量范围 4.2–4.5∶1 |
| 示例尺寸 | 900 × 210；如宽 1240，则高约 288 |
| 三栏比例 | 音乐 40%、日历 40%、镜子 20% |
| 音乐封面、镜子 | 正方形封面与正圆镜子等高、等宽，约为岛宽的 16% |
| 上栏 | 左侧“浮岛／工作台”导航，右侧设置入口，给物理刘海保留中心区域 |
| 视觉 | 近纯黑底、白色主字、灰色次字、蓝色今天日期、淡竖分割线、大底部圆角 |
| 定位 | 当前屏幕贴顶居中，不允许拖离刘海 |

桌面首页保持横向三栏，替换原先 420px 宽的纵向速览布局。现有完整工作台可以继续承载待办、笔记、链接、录音和设置；首页改版不要求删除这些功能或重建用户数据。

## 展开与反馈规则

| 状态 | 触发 | 显示 | 结束 |
| --- | --- | --- | --- |
| 静置 | 没有交互或活动 | 原有 200px × 菜单栏高度的贴顶刘海 | 点击或悬停进入首页；系统状态变化进入反馈 |
| 首页 | 点击；悬停约 280ms 可预览 | 横向音乐／日历／镜子 | Escape、点击外部或离开悬停区域后收起，具体保持规则沿用现有可交互与悬停两种模式 |
| 音量、亮度反馈 | 系统数值变化或岛内拖动 | 图标、滑条、真实数值；连续操作延长显示时间 | 停止操作约 1.5–2 秒收回；拖动时不关闭 |
| 短暂状态 | 已核实的耳机连接、充电等事件 | 状态图标、文字、可用的真实数值 | 短暂显示后回到原状态 |
| 持续活动 | 已核实的播放、计时、录音 | 紧凑状态；展开查看或控制 | 活动结束后移除，不用假波形冒充声音数据 |

自动反馈不得抢走正在输入的焦点。首页或工作台已经打开时，反馈应保持当前内容与输入，使用不遮挡操作的局部提示；不强制收起工作区。连续事件应合并，避免多个窗口相互覆盖。

预览的场景按钮用来独立查看几种状态，并不表示 Mac 系统监听已经接通。预览不会改变电脑音量、亮度，不会播放音乐或打开摄像头。

## 改版前的接入差距与目标

以下表格保留开始改版时的差距，完成状态见下方验收记录。

| 内容 | 改版前状态 | 接入目标 |
| --- | --- | --- |
| 输出音量／静音 | 已有音量实际读写；只有面板打开时查询 | 监听外部变化、显示反馈、拖动写入并回读；失败时恢复确认值 |
| 显示器亮度 | 未接入 | 内置屏幕真实读写与外部变化监听；外接屏按硬件能力判断，不能用覆盖黑色层冒充亮度 |
| 键盘背光 | 未接入 | 如纳入范围，确认当前机器是否支持读取和控制，再显示真实反馈 |
| 耳机／音频设备 | 未接入 | 监听连接、断开和输出切换；耳机电量仅在可读时显示，不以 Mac 电池值代替 |
| Mac 电量／充电 | 未接入 | 读取真实电量和电源变化，避免启动时把初始状态误当成刚连接 |
| 网易云音乐 | 可打开客户端，菜单支持播放／暂停／切歌；无完整歌曲数据 | 真实封面、歌名、歌手、专辑、播放状态；若加入进度则需实际读取。未获取时显示明确的空态 |
| 日历 | 当前仅显示本地周日期，点击进入待办 | 参考图的月份、周历、今日事项；“事项”来源需确定为浮岛待办、Apple 日历或两者 |
| 镜子 | 工作台已有摄像头功能 | 首页右侧圆形入口；主动点击后才开启，收起、离开首页或切换功能立即释放 |
| 计时／录音 | 主工作台已有番茄钟、录音 | 把真实活动状态同步到刘海；录音不因展示而自动开始 |
| 提醒 | 已有本地待办／番茄钟和 Codex、Claude、GPT 完成事件 | 将这些现有事件整合进岛内优先级；不能据此声称已读取所有 macOS 通知 |
| 专注／锁定等系统状态 | 尚未核实接入方式 | 独立验证可观测事件、权限与系统界面限制，再决定是否纳入 |
| iPhone 来电、导航、外卖等 | 未建立手机或第三方数据连接 | 用户已明确不用同步，不在本次范围内 |

“全部 iPhone 灵动岛显示内容”目前没有被定义成已支持清单。电话、导航、支付识别、第三方实时活动等依赖具体系统与应用能力，不作为纯外观改版可以自动完成的承诺。

系统自身的音量／亮度提示能否被可靠替换，需要在目标 Mac 上单独验证。仅显示一个新提示，不等同于系统旧提示已经消失。

## 验收时需要实际操作的场景

1. 面板关闭时按音量键、静音键和亮度键，岛内自动出现相应反馈，值与系统一致；连续操作不闪退、不抢焦点。
2. 岛内拖动控制真实系统数值，操作失败不显示虚假成功；外接屏不支持时清楚说明。
3. 主界面保持约 4.3∶1，音乐／日历／镜子约 40／40／20，封面与镜子等大，窄屏保证安全边距。
4. 网易云正在播放时，岛内信息和按钮状态与真实歌曲对应；未打开、未授权或无法读取时用真实空态。
5. 摄像头仅点击镜子才打开，收起后系统摄像头指示消失。
6. 原有待办、笔记、录音、密钥和偏好保留；安装验证以实际运行的应用版本和可见界面为准。
