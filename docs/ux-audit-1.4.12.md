# 浮岛 1.4.12 交互验收

日期：2026-09-07。范围为本机浮岛的常用按钮、日期编辑、番茄钟与返回流程。

## 修复与原因

| 现象 | 原因与处理 |
| --- | --- |
| 速览齿轮点不开 | 主进程已经发送设置入口，工作台渲染层却未允许 settings；统一使用现有页签列表接收。 |
| 番茄钟到点就停 | 原来是单次计时；改为默认专注 25 分钟、休息 5 分钟自动循环，两个界面显示同一阶段。 |
| 重启／睡眠后计时不连贯 | 持久化阶段、暂停状态和截止时间。过期阶段只转换一次，下一阶段给足时长。 |
| 空格操作按钮却收起工作台 | 全局快捷键拦截未排除按钮和快捷键录入；现在让这些控件接收空格。 |
| Escape 没有先关小浮层 | 增加日期、API、快捷键浮层的优先关闭；保持工作台展开。 |
| 日历打开时截止时间被改 | 旧分钟选择按 5 分钟取整且打开时立即写入；现在精确到分钟，只有选日／调时才保存。 |
| 跨天仍使用旧默认日期 | 刷新函数依赖已经移除的旧时钟元素，提前返回；日期刷新与时钟元素分离，手动日期保留。 |
| 修改名称时草稿丢失 | 日期收起／每分钟重绘重建输入框；保留草稿和光标，关闭日期浮层不重建正在点击的行。 |
| 修改截止日期后不再次提醒 | 重新设截止日期时清除旧提醒标记。 |
| 老待办无法改名 | 无截止时间的历史数据被保存验证拒绝；允许保留空日期单独修改名称。 |
| 点不同日期结果都一样 | 周历／热力格现在选择日期并显示该日待办；“查看全部待办”继续打开工作台。 |
| 速览里选择时长易收回 | 时长选择框获取焦点时保持浮岛打开。 |

## 验证方式

测试使用独立临时 Electron 数据目录、真实 HTML/CSS/JS 和 preload。按钮先进行命中检查，再通过 Chromium 输入事件实际点击。系统启动应用、剪贴板、密钥、权限接口由本地替身承接，不使用用户数据。

- 速览设置齿轮 → preload → 工作台设置页；八个页签、返回浮岛。
- 1240×616 和 1000×600 下设置按钮、开关可滚动触达，无隐藏容器吞按钮。
- API 配置打开／取消／Escape、快捷键空格录入、聚焦按钮时空格操作。
- 四象限月份箭头与选日，跨年／月末／二月天数，精确分钟，不操作就不改日期。
- 调日期后保存名称、定时重绘保留光标、跨天默认日期刷新与手动日期保留。
- 25/5 连续三轮，暂停／继续／重置，休眠／重启恢复；工作台阶段实时同步到速览。
- 待办添加／完成／恢复／删除，笔记保存／编辑／切页保存／删除，链接保存／打开请求／删除。
- 录音资料页进入／API 配置／返回电脑状态，模拟密钥表单验证／保存／复制请求／删除。
- 现有回归测试继续覆盖摄像头生命周期、HUD、通知、Codex 状态、剪贴板与布局。

## 边界

这次检查验证应用内交互和边界调用。系统权限批准、真实麦克风／摄像头录制、外部服务凭证与网络返回并未通过自动测试冒充本机实测；没有修改用户权限或 Codex Hook 信任配置。计时长周期通过模拟真实时钟推进验证，无需等待多个 25 分钟。
