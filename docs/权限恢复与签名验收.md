# 浮岛权限恢复与签名验收

## 当前诊断

2026-09-04 检查当前安装的 `/Applications/浮岛.app`（1.2.1）：

- 系统设置中“辅助功能”和“录屏与系统录音”的浮岛开关均为开启。
- 完全退出并重启当前应用后，网易云控制仍报告缺少辅助功能权限；窗口列表仍报告缺少屏幕录制权限。
- 1.1.1、1.2.0、1.2.1 的代码签名要求分别绑定不同的代码哈希。
- 本机当前没有可用的代码签名身份。旧打包钩子固定执行临时签名。
- 未能读取系统隐私授权数据库，因此“新版身份与旧授权不匹配”是与观察结果一致的原因判断，不能把它当作已经确认恢复。
- 正常系统界面的“添加应用”操作被自动审批拦截，理由为没有明确的权限变更授权。没有修改隐私数据库，没有变更权限开关，也没有绕过审批。

密码用于确认当次系统操作，不会为不断变化的应用身份维持授权。安装成功、签名校验通过、设置开关显示开启，都不能替代功能验收。

## 已准备的代码修复

打包钩子支持 `FUDAO_SIGNING_IDENTITY` 指定固定代码签名证书的 SHA-1 标识。指定身份不可用时构建失败，不降级成临时签名。未配置时仍保留上游临时签名流程，但明确提示它不能跨版本保持同一授权身份。

选择固定证书时，构建必须显式设置 `mac.identity=null`，由钩子统一签名并阻止后续自动签名覆盖。缺少这一设置同样拒绝构建。

此功能不会创建证书、导入私钥、修改钥匙串信任、授予系统权限或改写签名身份要求。准备代码不等于已经在本机配置固定签名。

## 待用户明确授权的操作

1. 配置一个用于浮岛的固定代码签名身份；如新建本机签名证书，其私钥只保存在用户钥匙串，不写入源码、日志或聊天。
2. 使用该身份打包，校验后替换应用；保留现有应用备份和用户数据。
3. 通过正常系统设置，为确切路径 `/Applications/浮岛.app` 重新登记辅助功能、屏幕录制，以及使用 System Events 控制网易云和窗口所需的自动化权限。
4. 若出现密码或 Touch ID 提示，由用户在系统窗口完成。

不能关闭系统保护、直接修改授权数据库、使用仅匹配应用名称的宽松签名要求，或借用另一应用的权限。

## 安装版验收

- 在当前安装版里点击网易云播放、暂停，验证真实播放状态变化；随后恢复用户原有播放状态。
- 从当前窗口卡片读取实际窗口，点击用户指定的一个窗口，验证它确实到达前台。
- 退出、重启同一安装版，再次确认权限和功能仍然有效。
- 下一次使用相同证书的更新应另行验证授权连续性。不能仅凭证书配置就保证所有 macOS 隐私授权永不重置。
- 网易云歌名、封面与进度目前没有真实数据来源，属于独立接入缺口；播放控制恢复不能作为元数据已经完成的依据。
