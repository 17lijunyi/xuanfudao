# 系统提示替换与本机验收

2026-09-04，本地浮岛 1.4.2，安装位置 `/Applications/浮岛.app`。

## 本机结果

- 45 个运行文件与项目源码一致，辅助进程和应用签名验证通过；原应用与本地数据已备份。
- 安装版正常响应只读健康检查，版本为 1.4.2。
- 折叠窗口实际为 360 × 34，贴顶居中；中央 200，左右各 80，下角 6。隔离界面的像素检查确认旧边缘位置已经覆盖。
- 安装版报告 `enabled: true, active: false, permission: required`。因此当前电脑上的按键接管**尚未生效**，仍需用户完成辅助功能授权，之后再用真实音量、亮度键验收。
- 授权入口：浮岛「设置 → 音量与亮度 → 前往授权」。系统开关必须由用户确认，不需要向代理提供密码。

## 行为

获得授权后，音量、静音和可访问内置屏亮度按键由浮岛处理；写入成功才消费按键。普通步进 1/16，Option + Shift 精调 1/64。持续按键会持续反馈，上下限仍有提示。没有可读写的单个主音量属性时交回系统；不逐个声道尝试写入。

退出、关闭开关或失去授权时释放接管；拦截异常停止后，用户可点「重新启用」。未授权时不重复显示被动音量／亮度提示。控制中心与其他软件自行发起的系统浮层不在按键替换范围内。

新安装默认启用接管意愿；每位用户首次仍须自行批准系统授权。程序不改系统权限库、不停止系统界面进程，也不记录普通键盘内容。

## 验收边界

按键配对、重复按键、静音长按、失败放行、停止后迟到响应、辅助进程重启、授权状态、显式重试和界面尺寸均有隔离检查。模拟检查不代表本机辅助功能已授权，也不代表物理键验收已完成。

本次真机启动曾阻塞在钥匙串读取。现已移除启动解密：API 摘要只读取是否保存，密钥库仅在用户打开密钥页后读取；重装后健康接口恢复正常。原加密数据没有修改。
